Questions

Common questions

Do you file CBAM declarations?

No. The authorised declarant files. Climoz builds the system that produces and evidences the emissions data behind the declaration.

Do you verify the figures?

No. Verification is done by an accredited verifier. We make sure every figure is traced to its source so verification goes smoothly.

Can we just use default values?

Default values are designed to be conservative, so they often overstate emissions. The system shows actual and default figures side by side so you can see what measuring is worth.

We are an Indian exporter. Is this for us?

Yes. Producers outside the EU and UK are the source of the data importers need. See our India page for how CBAM fits with BRSR and CCTS.
